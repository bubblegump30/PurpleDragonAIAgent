# Support

Start with the in-app Guide (F1), [README.md](README.md), and the [downloads folder](downloads/README.md).

For startup problems, run `Diagnose-Startup.bat` locally and review its output. For connection problems, use Settings to refresh/test the local model explicitly. For suspected package drift, inspect Release Trust before changing files.

Use the issue templates for reproducible bugs, accessibility barriers or feature requests. Include the release, platform and a minimal example. Redact paths and private data from screenshots/logs. Never post settings, conversations, vault files or credentials. Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the ordinary bug form.

This project is maintained on a best-effort basis by KyleAustin85. Support is not a managed service and no response time is guaranteed.
